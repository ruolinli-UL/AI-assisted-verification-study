# Blank study questionnaires (Microsoft Forms instruments)

This folder transcribes the **blank questionnaire items, response options, and branching instructions** documented in **Section 6.2, "Questions asked", of the research team's ethics application** (`2026_09_07_S&E Beyond Task Success_revised.docx`, pp. 19–24 of the application). The original study forms were administered through **Microsoft Forms**, with university-account access restrictions. These Markdown files are **documentation copies**, not live forms, Microsoft Forms exports, or participant responses.

| File | Study stage | Instrument |
|---|---|---|
| [`01_pre_task_consent_background.md`](01_pre_task_consent_background.md) | Prior to study | Information, mandatory consent gate, background questionnaire |
| [`02_private_judgement_snapshots.md`](02_private_judgement_snapshots.md) | Phase A before/during collaboration | One branched form used for **Snapshot 1** and **Snapshot 2** |
| [`03_individual_diagnostic_form_b.md`](03_individual_diagnostic_form_b.md) | Phase B, following collaborator removal | Independent release-readiness judgement |
| [`04_post_task_questionnaire.md`](04_post_task_questionnaire.md) | After both phases | Perceived difficulty, collaboration influence, participant reflection |

**Protocol distinction:** Snapshot 1 and Snapshot 2 were administered through the **same Microsoft Form** with a snapshot-selection question and branching. They are not two separate source instruments. In the phase-specific study flow, these individual judgements were collected privately (not disclosed to the collaborator before submission).

**Disclosure and source fidelity:** Question wording and response options below are transcribed from the ethics-protocol version, preserving its wording. Item types, required status, and branching are documented. The forms' underlying configuration, final deployed Microsoft Forms version, and any later changes were not independently exported or verified. The original questionnaires were gated; the public material reproduces questionnaire wording but intentionally omits their live submission URLs, the participant information-sheet body, and account/operational links. Do not attempt to submit responses through the repository.

**Privacy:** There are no submitted responses, participant IDs, personal data, or consent records in this folder. An empty question asking for a participant code is not a participant record.
