# C. Individual Diagnostic Task (Form B)

**Source:** Ethics application, Section 6.2, pp. 22–23. **Administration:** Microsoft Forms after the collaborator-removal phase. No participant responses included.

## Instructions shown to participants

Complete this form independently, without assistance from your previous human or artificial intelligence collaborator. Inspect the supplied requirements, Java implementation and available tests. Create and run any tests you consider necessary, and leave the resulting code and tests in the supplied working folder.

### Q1 — Required; single-line text

Please enter the participant code provided by the research team. Do not enter your name or student number.

### Q2 — Required; single choice

Based on the available evidence, is the component ready for release, not ready for release, or are you unsure?

- Ready for release
- Not ready for release
- Unsure

### Q3 — Required; multi-line text

What evidence most influenced your final judgement, and what uncertainty, if any, remains?

### Q4 — Required; multi-line text

What action, if any, would you take before release, and why? Implement any code or test changes in the supplied working folder.

### Q5 — Required; single-line text

How confident are you in your final judgement? Enter a number from 0 to 100, where 0 means not at all confident and 100 means completely confident.
